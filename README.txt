Ember & Spice — final image-matching portfolio build

Each menu item now has a unique image address generated from the exact dish name, so Zinger Burger searches for Zinger Burger, Chicken Biryani searches for Chicken Biryani, etc.

A browser error fallback is included so a broken remote thumbnail does not leave an empty image box.

Note: these are third-party image-search thumbnail URLs, not owned restaurant photography. For a real client launch, replace them with licensed/owned food photos or a properly licensed stock-image source.
